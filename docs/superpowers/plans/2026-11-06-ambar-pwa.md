# Ámbar PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PWA instalable para Ámbar Steak House con landing, dos menús priorizados por hora, pedidos (panel + WhatsApp), tarjeta de fidelización por QR/NFC y panel admin oculto.

**Architecture:** SPA React/Vite (HashRouter) servida como estático. Supabase es el único backend: tablas con RLS sin políticas para `anon`; todo acceso por RPC `SECURITY DEFINER`. Migraciones aplicadas con la Management API usando `SUPABASE_ACCESS_TOKEN` del entorno.

**Tech Stack:** React 18, Vite, TypeScript, react-router-dom 6 (HashRouter), motion, vite-plugin-pwa, @supabase/supabase-js 2, canvas-confetti, qrcode, vitest, Python+Pillow (assets).

**Spec:** `docs/superpowers/specs/2026-11-06-ambar-pwa-design.md`
